# P3.5 i18n convention

Lightweight self-written dictionary (no `next-intl`). Module: `web/src/lib/i18n.ts`.

## Locale resolution

1. URL query `?lang=zh|en` wins.
2. Else client `localStorage` key `genepage_lang` (`LangSwitch` hydrates URL).
3. Else default **`zh`**.

Server components use `resolveLocale(searchParams)`. Client switcher writes both URL and `localStorage`.

## UI dictionary

- `t(locale, key, vars?)` — shell strings: masthead, buttons, empty states, disclaimer chrome, catalog, print bar, CSV link, section labels.
- Keys live in `zh` / `en` tables inside `i18n.ts`.
- Colours unchanged (`#F4F0E6` / `#1A1A1A` / `#8B3A2F`). No clinical advice invented.

## Gene content pickers

| Field | Rule |
|-------|------|
| Deck | `lang==='en' ? (deck_en \|\| deck_zh) : deck_zh` via `pickDeck` |
| Tissue label | `lang==='en' ? name : (name_zh \|\| name)` via `pickTissueName` |
| Captions | `pickCaption(expression\|structure, locale)` → `caption_en` / `caption_zh` |

Edition **0.3.0-p35** ships `deck_en` and `caption_zh` / `caption_en` on expression & structure for all 10 demo genes. **`deck_en` fallback to `deck_zh` is defensive only** — acceptance uses real English decks.

## Routes

- `/`, `/g/[symbol]`, `/g/[symbol]/print` all read `searchParams.lang`.
- Links use `withLang(href, locale)` so `?lang=` is preserved (catalog, print, home).
- Print toolbar / PrintBar follow current lang.
- Search forms carry a hidden `lang` input.

## API

- No `Accept-Language` filtering; gene JSON is passed through in full.
- TypeScript `Gene` includes optional `deck_en`, `expression.caption_*`, `structure.caption_*`.
- `/api/search` also returns optional `deck_en` for catalog snippets.

## Components

- `LangSwitch` (masthead, 版式视觉壳) — client; updates URL + `localStorage`. Do not reintroduce `LanguageSwitcher`.
- `Lang` is an alias of `Locale` (`"zh" \| "en"`).

## Acceptance URLs

- `http://127.0.0.1:3000/g/TP53?lang=zh`
- `http://127.0.0.1:3000/g/TP53?lang=en`
- `http://127.0.0.1:3000/g/TP53/print?lang=en`
- `http://127.0.0.1:3000/?lang=en`
