# P3.5 改版 Brief — A+C（加重刊 + 轻交互 / 中英）

**锁定：** 2026-09-29 · 用户确认主方向 A+C；**不做** B 专题号（封面故事 / 编辑选读二期再议）。  
**约束：** 气质仍 C；三色不变（`#F4F0E6` / `#1A1A1A` / `#8B3A2F`）；非诊疗声明保留；本机 `/workspace/genepage` only，禁云端。  
**目标：** 解决「过于简单、亮点不足」；强制交付中/英切换。

---

## 1. 产品目标

在现有基因一页简报上，把期刊层次做重，并加上克制的交互与双语，使截图/印刷页一眼可辨、值得当汇报附页。

验收（相对 P3）：
1. `/g/TP53` 视觉层次明显重于改版前（破栏或要闻区升级、图注规范落地、至少一种印刷风图表增强）。
2. 报头可一键切 zh / en；UI 壳 + 导语/组织名随语言切换；刷新后语言偏好仍在。
3. Print 页跟当前语言；CSV / 数字 / sources 语言无关字段行为不变。
4. 不做 SaaS 仪表盘风；不做专题号内容块。

---

## 2. 版式（Gazette 版式 · 主责）

只改 `web/`（必要时 `frontend-mock`、`DESIGN_BRIEF` 增量节）。

**加重刊**
- 报头：更强刊名层级；卷期 / 数据截至更显眼。
- 要闻三数：更大数字、更清晰图注；可破栏或加细文武线。
- 双栏：身份 | 表达/结构层次拉开；表达图升级（小 multiples 或更清晰条形 + 完整图注）。
- 染色体标尺示意图（简版即可）。
- 结构区：AlphaFold 外链 + 更完整占位/预览框（有图用图，无图期刊口吻空态）。
- 变异区：P/LP 条 + 可展开明细（轻交互）；空态双语。
- 图注规范：落实并扩展 `docs/FIGURE_CAPTION.md`。

**轻交互（视觉侧）**
- 语言切换控件（报头右侧，zh | en）。
- 表达组织 hover/focus 不破坏印刷感。
- PrintBar 文案随语言。

**不做：** 霓虹、毛玻璃、大圆角卡片墙、专题封面。

## 3. 数据（Gazette 数据 · 主责）

不改视觉。

**双语字段增量**
- 基因 JSON：保留 `deck_zh`；新增 `deck_en`（10 基因均需有合理英文导语）。
- 组织：`name`（英）+ `name_zh`（已有则校验）；图注长句可由前端字典拼，数据只保证短名。
- `caption_zh` / `caption_en`（表达图、结构图）可选但推荐。
- `sources`、`data_as_of`、ClinVar 计数、坐标：语言无关。
- `edition`：改版合并后建议升为 `0.3.0-p35`（与总编确认后写入）。
- 更新 `index.json` / CSV 导出列说明（`rebuild_catalog.py`）；`data/CSV_EXPORT.md` 注明哪些列双语。

脚本：扩展 sync/merge 或手写补全 `deck_en`；跑完回频道给路径与抽查。

## 4. 工程（Gazette 工程 · 主责）

不改配色叙事。

**i18n**
- UI 字典（自研轻量或 `next-intl`，择一简单可维护）。
- `lang=zh|en` 查询参数 + `localStorage` 持久化；默认 `zh`。
- 基因页按 lang 选 `deck_*`、组织显示名、Print 文案。
- API：透传双语字段即可，不必按 Accept-Language 裁剪（前端选字段）。
- 路由：`/`、`/g/[symbol]`、`/g/[symbol]/print` 均尊重 lang。
- 保持 `:8000` / `:3000`；重启后自检 200。

文档：`docs/P35_I18N.md`（约定一页即可）。

## 5. 顺序

1. 数据出 schema 增量 + 补 `deck_en`（可与版式并行出视觉）。
2. 工程先接线 i18n 壳与字段选择。
3. 版式在真双语字段上压加重刊层次。
4. 总编联调：`/g/TP53?lang=zh` / `?lang=en`、print、目录。
